This is the big one. Moonfin on Roku has been rebuilt screen by screen to match the rest of the Moonfin clients, so the detail screens, the navigation bar, the sidebar, the login screens, the search results, the media bars, the track pickers, the settings tree, and the library sort and filter dialog all look and behave the way they do on other TV, mobile, and desktop clients. On top of that, Seerr is now built into the normal detail screen instead of living in its own world, home rows can be picked and arranged with no eight row cap, there's a real in-app keyboard, and new installs get a setup wizard. It's a version 2.0 because almost nothing looks the same.

## Features

### Setup Wizard

- New installs now start with a setup wizard. It asks where you want the navigation bar, which media bar style you like, whether you want classic or modern home rows, and which detail screen style you prefer, in that order, since the navbar is the frame everything else sits in.
- Each question comes with a preview drawn from your own artwork, so you're picking from what it'll actually look like.
- It only asks what you haven't already answered. A setting that came down from your server profile or that you chose yourself is skipped, so a second Roku on the same account usually sees nothing. There's a short tour at the end, and it only appears alongside a real question rather than standing between you and the app.

### Seerr

- Seerr now lives inside the normal detail screens. The separate Seerr-only screen is gone, and its rows and tabs sit alongside everything else on the detail screen the rest of the app uses.
- A requests and issues screen, with status chips, so you can see what you've asked for and what's happening to it.
- The request flow is one dialog rather than a chain of screens.
- Calendar and Seerr cards show their details, and a release opens in Seerr.

### Home Screen

- A home row picker, and the eight row cap is gone. Pick which rows you want and put them in the order you want them.
- Per collection, genre, and playlist rows, so a specific collection can have its own row rather than being buried in a generic one.
- The full home layout syncs with your server, not just a flat list of row names, so a layout built on another client arrives intact.
- The home row progress bar matches the other clients, modern row card images fade in rather than popping, and cards without artwork show placeholder text.

### Libraries

- In-library search, so you can find something inside a big library without leaving it.
- A new sort and filter dialog matching the one on Smart-TV.
- Library posters get the caption and header the other clients use.

### Detail Screens

- The classic and modern detail screens, their buttons, and their tabs all match the other clients.
- The action row can be arranged, so the buttons you use sit where you want them.
- A read more toggle, since a long synopsis had no way to be opened.
- The person screen was reworked to match the other clients.
- Ratings are filtered and ordered by your source picker, and the badges were redone.

### Media Bar

- The Aya media bar is here, bringing Roku to all six styles the other clients have.
- The Moonfin, MakD, Gallery, and Banner bars were each brought in line with their counterparts elsewhere.
- Mixed libraries are offered in the media bar and shuffle pickers, where they had been missing.

### Player

- Trickplay previews while scrubbing.
- The OSD buttons are ordered like the other players, and they can be rearranged.
- Skip Intro and Up Next match the other clients, as do the track pickers and the subtitle downloader.

### Elsewhere

- A real in-app keyboard, used for every text field, with the letter rows following your language and accented characters on a held key.
- An account switcher on the navbar avatar.
- The settings tree matches Moonfin-Core, so a setting sits where you'd look for it if you use another Moonfin client.
- The login screens match Smart-TV, and search results match the other clients.
- In-app diagnostic logging, with a log viewer and an option to send crash reports to your own server.
- Themes keep their colors. Most of a theme's palette was being dropped on the way in.

## Bug Fixes

### Seerr and Sessions

- Seerr sessions persist when you switch devices. Background task threads were signing in as a generic Roku device rather than this one, so anything keyed to the device came back empty.
- Seerr recommendations no longer crash the detail page when Seerr is in the navigation bar.

### Home and Settings

- Server home rows are fetched again. A settings sync key was being built without its backticks, so the lookup never matched and rows pushed from the server never arrived.
- Rows that were offered but never appeared are built.
- Row toggle keys work, and Seerr rows sync the way Moonfin-Core does.
- A picked row turns its list on when you pick it.
- The home screen handlers rebind when the navigation bar moves, and the navbar position is held to one this client can actually draw.
- Recent items sort correctly. The sort was calling a method arrays don't have.
- MDBList ratings are asked for once when there's no key of your own, instead of repeatedly.
- The sidebar stays hidden on screens that should hide it, and server rows are gated behind their toggles in the row picker.

### Playback

- Playback info reports transcoding. It was reading from a session list that didn't hold it.
- A paused mini-player no longer blocks video playback.
- Theme music stops before the video player takes over.
- The trickplay image stays on screen at the end of the seek bar.
- Previous rewinds to the start when there's nothing before the current item, and the button shows either way.
- The adjacent episode window is pre-fetched in the background, so the previous and next episodes are ready when you reach for them.

### Layout and Text

- Overview text sizes correctly with non-standard theme fonts on both detail screen styles, with the line pitch measured rather than assumed and the width trimmed.
- A focused episode stays on screen on season pages that have no description, with the page shift derived from the description rather than assumed.
- Studio and network logos are the only images scaled to fit, and the focus card treatment resets properly.
- Four small screens that were losing text they meant to show now show it.
- The modern detail row folds under More beside the up next card.
- Episode descriptions stay hidden where you asked, covering episode items and season rows.
- Duplicate titles are folded away, using provider ids and a title and year fallback.
- Search results dropped an incompatible image field that was warning, Seerr results moved to the bottom of the All tab, and the person screen dropped an invalid field on a text object.
- The keyboard hands focus back when it closes.
- Quick Connect lets go of its poll task between ticks instead of holding it.
- Item state goes back on the node after you mark something watched.
- Modern rows reflow on first boot, and the first modern row reflows when content loads with nothing focused.
- Fixed the home crash when a calendar row builds its cards, and the row picker double press crash.
